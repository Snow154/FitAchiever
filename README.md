# FitAchiever

Jednoduchý local-first tréningový denník vytvorený v Expo, React Native a TypeScripte.

Projekt má zároveň slúžiť ako praktické učenie Reactu a TypeScriptu. Codex je v ňom primárne coach; aplikačnú logiku píše používateľ. Pravidlá spolupráce sú v [AGENTS.md](./AGENTS.md).

## Jedna veta o produkte

Do svojho tréningového hubu si pridám cviky z offline katalógu, rýchlo k nim zapisujem série, váhu, opakovania a poznámku a vidím ich históriu.

> Aktuálny stav: discovery a plánovanie. Expo projekt ešte zámerne nie je vygenerovaný.
